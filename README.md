# Daily Expense Tracker 💰

A beginner-friendly Python project that helps users record and manage their daily expenses.

## Features

- Records multiple daily expenses
- Categorizes expenses (Food, Travel, Shopping, etc.)
- Calculates total daily spending
- Displays category-wise spending
- Counts the total number of expenses

## Technologies Used

- Python
- Lists and Dictionaries
- Loops and Conditional Statements
- `sum()` and `len()` Functions

## How to Run

1. Install Python.
2. Clone or download this repository.
3. Open the project folder in your terminal.
4. Run:

```bash
python main.py
```

## Expense Tracking Process

- Enter the expense amount.
- Enter the expense category.
- Add more expenses if needed.
- View total daily spending.
- View category-wise spending and total expense count.

## Learning Outcome

Practised Python lists, dictionaries, loops, conditional statements, and built-in functions through a simple real-world application.
